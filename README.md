# Portfolio d'Ingénierie — Mohammed HSINY 🚀

Portfolio web interactif moderne et performant présentant le profil, les réalisations d'ingénierie, les immersions industrielles et le leadership associatif de **Mohammed HSINY** — Élève Ingénieur en Génie Électrique & Contrôle Industriel à la FST de Mohammedia.

---

## 👨‍💻 Profil & Recherche
- **Identité** : Mohammed HSINY
- **Spécialité** : Génie Électrique & Contrôle Industriel
- **Établissement** : Faculté des Sciences et Techniques (FST) de Mohammedia
- **Objectif** : Recherche active d’un **Stage PFE (6 mois)** à partir de **Janvier 2027**
- **Domaines de prédilection** : Systèmes Embarqués, Systèmes Autonomes, Drones, Robotique Mobile, Contrôle Industriel & SCADA, R&D & Défense.

---

## 🛠️ Stack Technique
- **Frontend** : React 19 + Vite
- **Animations & Motion** : Framer Motion
- **Défilement Ultra Fluide** : Lenis Smooth Scroll
- **Icônes** : React Icons (FontAwesome)
- **Typographie** : *Plus Jakarta Sans*, *Space Grotesk*, *JetBrains Mono*
- **Architecture CSS** : Vanilla CSS modulaire & tokens personnalisés (Dark-Tech Cyber-Industrial)

---

## 📂 Structure des Sections
1. **Hero** : Présentation percutante avec statut de disponibilité PFE 2027, métriques clés, animation canvas et boutons d'action rapide.
2. **Profil & Formation** : Biographie, vision R&D, citation d'Edison, piliers technologiques et parcours académique complet (FSTM / FSTE).
3. **Immersion Industrielle** : Retours d'expériences chez **Groupe OCP** (SCADA MT), **Ciments du Maroc** (Maintenance & Instrumentation) et **Marsa Maroc** (Fiabilisation & IoT).
4. **Projets d'Ingénierie & Prototypage** : 8 projets concrets (Drones HT/FPV, Robot SkyPharma H-Bot, Bras 6-DOF, Flotte ADAS, Robot humanoïde, Suiveur PID, Logique séquentielle) avec filtres de catégories et modales de spécifications détaillées.
5. **Arsenal Technique** : Matrice interactive des compétences matérielles et logicielles (STM32, ROS, SCADA Ignition, Siemens, Schneider, SolidWorks, Python, C++, IA).
6. **Leadership & Distinctions** : Présidence du **Club RoboThings**, fondation des **RoboDays** et podiums en compétitions nationales & internationales.
7. **Contact & Documents** : Copie d'email en 1 clic, lien direct WhatsApp, LinkedIn et téléchargement direct du CV PDF et du Portfolio PDF (8 pages).

## 💻 Démarrage Local

```bash
# 1. Installer les dépendances
npm install

# 2. Lancer le serveur de développement
npm run dev

# 3. Compiler pour la production
npm run build
```

## ☁️ Déploiement sur Vercel

1. **Pousser sur GitHub** :
   ```bash
   git init
   git add .
   git commit -m "feat: portfolio Mohammed HSINY"
   git branch -M main
   git remote add origin https://github.com/<votre-username>/<nom-du-repo>.git
   git push -u origin main
   ```
2. **Connecter sur [Vercel](https://vercel.com)** :
   - Cliquez sur **Add New...** -> **Project**.
   - Importez votre dépôt GitHub.
   - Framework preset détecté automatiquement : **Vite**.
   - Cliquez sur **Deploy**.
